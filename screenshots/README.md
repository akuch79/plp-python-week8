# Required assignment screenshots

The assignment requires five screenshots: one showing the main menu rejecting an invalid choice, plus one showing each of the four tools in action. Capture these from a real run of `toolkit.py` and save them in this folder using the filenames below.

- `01-invalid-menu-choice.png` — enter an invalid menu choice and show the error message.
- `02-calculator.png` — run a calculation and show the result.
- `03-todo-list.png` — add and display a task (optionally show removing it too).
- `04-number-guessing-game.png` — show a guess and the game's response.
- `05-name-formatter.png` — enter a name and show the formatted result.

Suggested capture workflow:

1. Run `python toolkit.py` in a terminal (or `py toolkit.py` on Windows).
2. Exercise each path above; restart the program as needed.
3. Capture the terminal or application window with your operating system's screenshot tool.
4. Save the actual image files here with the listed names, then commit and push them.

The image files are intentionally not represented by placeholders: screenshots should document the program running on your machine.
