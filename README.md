
# Personal Mini-Toolkit

**Developer:** Margaret Akuch Deng

## Project Description

Personal Mini-Toolkit is a beginner-friendly Python application that brings together four useful tools in one menu-driven program.

The program includes:

1. Simple Calculator – Performs addition, subtraction, multiplication and division.
2. To-Do List – Allows users to add, view and remove tasks.
3. Number Guessing Game – Allows users to guess a randomly selected number.
4. Name Formatter – Formats names into title case.

## Technologies Used

- If, Elif and Else statements

## How to Run the Program

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python toolkit.py
```

On Windows, you can also use:

```bash
py toolkit.py
```

5. Select a tool from the menu.
6. Follow the instructions displayed.
7. Select option 5 to quit.

## Project Reflection

During this project, I learned how to combine different Python concepts to build one complete program. The hardest part was connecting all the tools to the main menu while making sure the menu continued running. The bug that took me the longest to fix was handling invalid user input without stopping the program. I also learned how to use lists to add, display and remove tasks. Testing each tool helped me understand loops, conditionals and functions better. I am proud that I was able to build four different tools in one application. If I had one more week, I would add the ability to save tasks in a file so that they remain available when the program is restarted.
